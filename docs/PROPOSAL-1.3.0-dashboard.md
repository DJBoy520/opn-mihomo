# OPNsense Mihomo 插件界面重设计方案（用户提案 2026-10-24，原文存档）

> 目标：把当前单页长表单改造成「现代 Dashboard」风格，保留 OPNsense 左侧菜单与顶栏不动，仅重写 `/ui/mihomo` 主视图。
> 原则：实时流量/连接数/节点延迟不在本页展示（用户另有客户端查看），本页只做「状态概览 + 配置管理」。

---

## 1. 信息架构

当前所有内容堆在一个滚动页里，重设计后拆为 **4 个 Tab**，Tab 切换用 OPNsense 原生 `tabcontrol` 组件（无刷新切换）：

| Tab | 名称 | 内容 |
|---|---|---|
| 1 | 概览 | 状态卡片行 + 快捷操作 + 订阅状态摘要（默认落地页） |
| 2 | 基本设置 | 运行参数表单（启用、日志级别、传输模式、LAN 暴露） |
| 3 | 订阅与策略 | 订阅地址、自动更新、策略来源、更新历史 |
| 4 | API 与面板 | 面板地址、密钥管理、客户端接入指南（默认折叠） |

**状态卡片细节：**
- 卡片高度统一 88px，白底，圆角 12px，阴影 `0 1px 3px rgba(0,0,0,0.06)`。
- 第一行 4 张卡片等宽，第二行「分流规则」单独一张（或改为 5 张一行自适应，小屏自动换行）。
- 「状态」卡片左侧一个 10px 圆形指示灯：
  - 运行中：#22c55e，带 2s 一次的 pulse 动画
  - 已停止：#9ca3af，静止
  - 异常/启动失败：#ef4444
- 数字用 28px / 600 字重，标签用 12px / #6b7280。
- 节点数 / 策略组数 / 规则数 数据来源：当前页面已有的「最近更新状态」字段（节点数量、策略组数量、分流规则数量）。

**快捷操作按钮规范（重点改掉彩虹按钮）：**
- 根据运行状态切换主按钮：
  - 运行中 → 主按钮 = **停止**（红色实心 #dc2626，白字）
  - 已停止 → 主按钮 = **启动**（绿色实心 #16a34a，白字）
- 「重启」「重载」= 次按钮（白底灰边框，悬停变深灰），不再用橙色/蓝色。
- 主按钮宽度 120px，次按钮 90px，高度 38px，圆角 8px。
- 点击主按钮后弹确认框（OPNsense 原生 confirm），按钮进入 loading 态（转圈 + 禁用）直到状态返回。
- 右侧「启用 Mihomo」开关单独成组，与运行控制分开——启用=开机自启/配置生效，启动/停止=进程控制。

**订阅状态卡片：**
- 一行内：掩码后的订阅地址（等宽字体）+ 右侧徽章（成功绿 / 失败红）+ 相对时间。
- 「立即更新」小按钮（默认样式），点击后按钮变 loading，下方刷新更新历史。

## 3. 视觉规范

### 配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 页面背景 | `#f5f7fa` | 比 OPNsense 默认稍冷 |
| 卡片背景 | `#ffffff` | |
| 卡片边框 | `#e5e7eb`（可选，有阴影就不用边框） | |
| 主文字 | `#111827` | |
| 次要文字 | `#6b7280` | |
| 强调色（主按钮/选中态） | `#2563eb` 蓝 | 替代 OPNsense 橙，和 Clash/Mihomo 社区一致 |
| 成功/运行中 | `#16a34a` | |
| 危险/停止 | `#dc2626` | |
| 警告 | `#d97706`，背景 `#fffbeb` | |
| 信息提示 | `#2563eb`，背景 `#eff6ff` | |

> 说明：OPNsense 顶栏仍是它自己的橙色品牌色，本插件内容区用蓝色强调色不冲突——左侧菜单是系统级，内容区是插件级，视觉上能区分。

### 间距与圆角
- 卡片 padding：20px
- 卡片间距：16px
- 卡片圆角：12px
- 输入框/按钮圆角：8px
- 表单行间距：20px
- 页面左右 padding：24px

### 字体
- 数字用 `font-variant-numeric: tabular-nums`（卡片上的节点数对齐好看）。
- 密钥/URL 用等宽字体 `ui-monospace, SFMono-Regular, Menlo, monospace`。

## 4. 交互与状态

1. **状态轮询**：概览 Tab 每 5 秒调一次后端状态接口（`/api/mihomo/service/status`，返回 `{running: bool, mode: string, nodes: int, groups: int, rules: int, last_update: iso, last_result: string}`），刷新状态卡片指示灯和按钮主态。其他 Tab 不轮询。
2. **启动/停止/重启/重载**：点击后按钮 disabled + spinner，操作完成后状态接口自然刷新。
3. **立即更新**：点击后按钮变 loading，完成后刷新「最近更新」区块 + 概览订阅状态卡片。
4. **保存并应用**：所有表单 Tab 共用，保存成功后顶部弹一个绿色 toast（OPNsense 原生 alert），不要跳页。
5. **确认弹窗**：停止服务、生成新密钥 这两个操作必须 confirm。
6. **登录后的落地页**：直接进「概览」Tab，不要再停在长表单上。

## 5. 需要改的文件清单（给 zcode 的提示）

假设插件源码结构是标准 OPNsense 插件布局：

```
src/OPNsense/Mihomo/
  Controller/
    IndexController.php        # 主页面，return 时 assign 所有状态数据
  Api/
    ServiceController.php      # 新增 status/reload/start/stop/restart 端点
    SubscriptionController.php  # 新增 update_now 端点
  forms/
    mihomo-general.xml         # 保留字段定义，不改
  views/
    index.volt                 # 【主要重写文件】加 tab 结构 + 卡片 HTML
  css/
    mihomo.css                 # 【新增】本方案所有自定义样式
  js/
    mihomo.js                  # 【新增】轮询、按钮 loading、tab 切换、复制端点
```

**关键技术点：**
- OPNsense 前端基于 Bootstrap 5，Tab 直接用 Bootstrap nav-tabs，不要引入新框架。
- 卡片、按钮、徽章用 Bootstrap 类 + 少量自定义 CSS 覆盖即可，不要引 Tailwind。
- 状态轮询用原生 `fetch` 或 OPNsense 自带的 `ajax` 工具，不要引 jQuery。
- 所有文字中文，与现有插件语言一致。
- 移动端响应式：状态卡片 row-cols-1 row-cols-sm-2 row-cols-lg-4。

## 6. 不在本次范围内

- 不做节点选择、策略组切换、连接日志——这些交给 `:9090/ui` 面板。
- 不做流量统计图、带宽曲线——用户另有客户端看。
- 不改 OPNsense 左侧菜单结构、顶栏、登录页。
- 不改后端业务逻辑，只加状态查询和操作的 API 端点（如果已经有就复用）。
