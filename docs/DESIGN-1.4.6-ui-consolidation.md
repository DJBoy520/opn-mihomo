# os-mihomo 1.4.6 WebUI 整合改版设计说明

版本目标：**1.4.5 → 1.4.6** ｜ 设计基准：`.private/ui-1.4.6/prototype.html`

---

## 1. 改版动机

在 1.3.0 与 1.4.5 版本中，WebUI 已完成了 Dashboard 化改造与运行状态信息整合。但在实际体验与宽屏展示中，依然存在三处视觉与布局层面的参差不齐：

1. **面板与 API 卡片密度失衡**：旧设计采用灰底两列表格 `.mihomo-kv`，将只读端点展示、外部链接、复制按钮、密码掩码以及折叠自定义密码输入框挤在单元格内，且包含已废弃的「内置面板」跳转链接，字段基线不统一。
2. **订阅卡片分栏与样式飘移**：采用 Bootstrap 栅格 `col-sm-6` 强行左右两列，左侧 checkbox 与右侧 select 控件高度和文字基线不齐，说明文案多处冗余；「最近更新状态」包含重复的规则与组数统计。
3. **策略组纵向双栏挤压与嵌套滚动**：采用左侧组列表（写死 `max-height: 620px; overflow-y: auto`）与右侧节点分页的左右分栏布局。当策略组达十几个时，左侧产生内部垂直滚动条；展开复合策略组时无法直观看到整条调用链。

---

## 2. 字段原语规范（`.mh-fields` 约定）

将「运行参数」中验证良好的优秀观感抽象为全局通用原语，形成五条统一硬规则：

1. **一行一字段**：标签在上（13px / 600 / `--mh-text`），控件在下，普通输入控件统一 `max-width: 460px`（长输入框使用 `.mh-input-wide` 铺满）。
2. **说明文字独占行**：字段辅助说明独占一行，置于控件正下方（12px / `--mh-muted`），不再与控件挤在同一直线上。
3. **行间虚线分隔**：虚线（`1px dashed var(--mh-card-border)`）仅出现在字段之间，卡片首尾不留分割线。同类只读数据汇总使用 `.mihomo-kv-strip`。
4. **动作区底部沉降**：操作按钮不混杂于字段内部，统一沉至卡片底部的 `.mihomo-toolbar`，上方以虚线分隔。
5. **少字段卡片锁双列**：字段较少的卡片（面板与 API、订阅）统一使用 `.mh-fields.is-2` 锁定两列网格，在屏幕宽度 `<720px` 时平滑自适应单列，避免宽屏下参差断行。

---

## 3. 面板与 API 卡片改造

- **值 / 操作 / 说明三段分离**：
  - 控制 API 地址：作为派生地址置顶只读展示，保留单键复制功能。
  - API 绑定地址与端口：拆分成两个独立的可编辑标准字段（`#api_bind`、`#api_port`），不再拼合展示。
  - 自定义密钥：由 `collapse` 折叠解开平铺，按钮由「应用」调整为「填入」，不产生即时写请求。
- **操作与提交收拢**：
  - 移除卡片头冗余的端口 badge 与已下线的「内置面板」整行。
  - 卡片底部保留唯一一颗「保存并应用」（`#btn_api_save`），一次性提交绑定地址、端口与密钥配置。
  - 在 `index.volt` 渲染完成后，自动 `hide()` 运行参数表单中重复的 `api_bind` 与 `api_port` 行，避免两处表单编辑冲突。

---

## 4. 订阅卡片改造

- **统一 `.mh-fields.is-2` 结构**：
  - 订阅地址铺满，下方说明精简。
  - 开关采用 `.mh-field.is-switch`（复选框在前、文本在后），与启用 Mihomo 行为完全一致。
  - 周期选择控件移除限宽与小号限制，高度统一为 32px 标准高，标题明确为「自动更新周期」。
  - 清理「关闭后仅能手动」、「保存与更新互相独立」等冗余文案，简练标明「改地址不触发拉取」。
- **最近更新状态横排**：
  - 改用 `.mihomo-kv-strip`（双列），仅保留「更新时间」与「更新结果」两项关键指标，去除与概览重复的节点/组/规则计数。

---

## 5. 策略组扁平折叠卡片体系（`.mh-glist`）

- **单列全宽折叠流**：
  - 彻底移除双栏布局与所有 `overflow-y: auto/scroll` 容器，全页只保留浏览器原生主滚动条。
  - 每个策略组占据一行全宽卡片，卡片顺序严格保持 mihomo 运行时声明顺序，不强行重排序。
- **卡片头信息整合（`.mh-ghead`）**：
  - 从左至右：折叠指示箭头、组名（截断 + title 全名）、类型 chip、当前生效节点、弹性撑开、成员构成（子策略数/节点数）、最优延迟、迷你延迟分布条、被引用反向链接 chip（点击平滑滚动并展开目标）、成员数量计数徽章。
  - 具备全键盘可访问性（`tabindex="0"` + Enter / Space 触发展开）。
  - 响应式处理：≥1200px 单行通栏；900–1200px 被引用标签折行；<900px 隐藏延迟分布条与被引用标签。
- **两行式成员卡片（`.mh-mb`）**：
  - 展开体（`.mh-gbody`）区分子策略（虚线边框 `.is-group`，点击跳转下钻）与实际节点（实线边框，点击确认切换）。
  - 上行成员名称，下行展示其当前选择、类型 chip、UDP 标识及子组成员数；右侧展示选中勾选图标或测速延迟数字。
- **状态维持与大列表保护**：
  - 10 秒定时自动刷新时，保持展开字典 `OPEN`、页面滚动高度 `scrollY` 以及实时搜索过滤词不变，避免打扰用户操作。
  - 单组展开若实际节点超过 200 项，默认渲染前 200 项并提示使用搜索缩小范围，兼顾首屏流畅度。
