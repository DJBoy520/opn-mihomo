opn-mihomo Package Repository

项目简介

opn-mihomo 是为 OPNsense 打造的 Mihomo（原 Clash Meta）深度集成插件仓库，提供透明代理、分流规则配置、Dashboard 面板集成及开箱即用的网络代理体验。

  • 🌐 Mihomo 透明代理集成
  • 🛡 自动配置分流与 DNS
  • 📊 Dashboard 仪表盘与运行状态

安装方法

进入终端，运行以下命令添加 opn-mihomo 存储库配置：

fetch -o /usr/local/etc/pkg/repos/opn-mihomo.conf https://djboy520.github.io/opn-mihomo/opn-mihomo.conf

pkg update -f

更新软件包数据库后，进入：

系统
└── 固件
    └── 插件

在插件列表中找到 os-mihomo 并点击安装；或在命令行直接执行：

pkg install -r opn-mihomo os-mihomo

删除仓库

rm -f /usr/local/etc/pkg/repos/opn-mihomo.conf
pkg update -f

删除仓库配置不会卸载已经安装的插件。

Overview

opn-mihomo provides official packaging and distribution for the OPNsense Mihomo integration plugin, supporting transparent proxy, DNS interception, dashboard embedding, and routing management.

  • 🌐 Mihomo proxy integration
  • 🛡 Transparent redirection & DNS
  • 📊 WebGUI dashboard integration

Installation

Open the terminal and run the following command to add the repository configuration:

fetch -o /usr/local/etc/pkg/repos/opn-mihomo.conf https://djboy520.github.io/opn-mihomo/opn-mihomo.conf

pkg update -f

After updating the package database, open:

System
└── Firmware
    └── Plugins

Locate os-mihomo in the plugins list and install it, or run via CLI:

pkg install -r opn-mihomo os-mihomo

Remove Repository

rm -f /usr/local/etc/pkg/repos/opn-mihomo.conf
pkg update -f

Removing the repository configuration does not uninstall plugins that are already installed.
